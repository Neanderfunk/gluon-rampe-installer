## Vorher prüfen

Dieses Image passt zum CPE710 mit Hardware 2.0. Die v1 braucht ein eigenes Image. Die Hardware-Version steht auf dem Aufkleber ("Ver").

**Wichtig:** TP-Link-Firmware ab Version **1.1.2** (Build 20251113) sperrt
fremde Firmware dauerhaft, auch über alle Notfall-Wege. Wenn dein Gerät noch
eine ältere Version hat: **nicht** auf die neue Version aktualisieren.
